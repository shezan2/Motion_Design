# Sources

What this skill took from where. Principles are restated in our own words; the only bundled third-party code is `scripts/look.py`.

## GitHub skills
| Skill | Licence | What was taken |
|---|---|---|
| motionmaxxing, github.com/Tejashmakwana/motionmaxxing | Apache-2.0 | the judgment ("what good is", when tropes are earned), the never-ship list, measured durations, the 12 eases (fitted here to cubic-beziers), stagger, overshoot, reading time, cursor physics, transition catalogue T1-T20, close rules, SFX placement and mixing targets, the gates G0-G5. `scripts/look.py` is bundled unchanged under its licence (`scripts/LICENSE-look.txt`). |
| HyperFrames motion doctrine and reverse-any-video, github.com/heygen-com/hyperframes | Apache-2.0 | the seam law (axis, direction, speed, phase), the current and reserved directions, carriers, causal motion, stillness before the climax, no idle wobble, 2-3 transitions per film; reading consecutive frames at every change when studying a reference |
| motion-design-skill, github.com/LottieFiles/motion-design-skill | MIT | motion personality per brand, primary/secondary/ambient layers, emotional intent first |
| Open Design motion-design, github.com/nexu-io/open-design | see repo | resolve the brief without stalling, the representative frame first, the compact beat map, a recurring motif connecting beats |
| video-shotcraft, github.com/Vincentwei1021/video-shotcraft | Apache-2.0 | the visual language grows from the product's own design tokens; templates lend structure and rhythm, never the skin; one hero move per shot; leave hold time (feedback always asked for slower, never faster); beat-synced cuts checked after render |
| text-to-lottie, github.com/diffusionstudio/lottie | MIT | the Lottie pipeline, player contract and behaviour anchors behind the Outtakes toolkit |
| remotion-dev/skills | see repo | the Remotion route for batch and data-driven variants; one set of scenes with a portrait/landscape layout context |
| huashu-art-motion, github.com/alchaincyf/huashu-art-motion | MIT | explainer grammars (kinetic type, keynote UI, Kurzgesagt, Vox) as kinds of film; separating aesthetic judgment from technical checks |
| promo-video skills, github.com/pedronauck/skills (MIT) and github.com/akcodez/promo-video-skill | see repos | the voiceover must match the picture; verify the voice timings and fix every overlap; scene lengths of 2-4 s; one set of scenes for both formats |
| design-motion-principles, github.com/kylezantos/design-motion-principles | MIT | UI motion realism for product shots (purposeful, frequency-aware motion) |

# Transitions: how beat A becomes beat B

Shezan's references run 15-20 seconds on 1-3 hard cuts: almost every change is a morph, a carried object or an effect that becomes the next scene. This file is the seam law (HyperFrames' motion doctrine), the catalogue (motionmaxxing plus the reference reels) and how to choose.

## 1. The seam law
**How A leaves decides how B enters.**
1. **Axis:** x stays x, y stays y, depth stays depth.
2. **Direction:** never mirror it. In depth, growing means pushing in and shrinking means pulling back: a shrinking exit answered by a grow-from-small entrance is a mirrored vector, the most common mistake.
3. **Speed:** B's starting speed matches A's final speed (mirrored curves: accelExit out, a matching ease-out in, B picking up at least halfway along its path).
4. **Phase:** cut mid-motion on both sides. Settling to rest before the cut, or starting from rest after it, is a dead beat.

**The current.** Pick one dominant direction per film (left is the default) and use it for ordinary "next" seams. Other directions mean something:

| Direction | Meaning |
|---|---|
| The current (left) | next beat, neutral progress |
| Up | a conclusion or reveal rises above what came before |
| Push in (depth forward) | going deeper into the same thought |
| Pull out (depth back) | arrival: something bigger lands |
| Burst outward | leaving a world |

Never run consecutive seams in opposite directions without a cause (a click, an impact, a new chapter).

**Carriers.** The eye follows objects. The strongest seams hand a concrete thing across the cut at the same position and speed: a cursor mid-path, a container that docks into the next layout, a mark flying into its slot, a dot, a line, a word. With no natural carrier, the scene's hero carries it.

**Cause.** Each move is launched by the last one: click, squash, release, flight, impact, reveal. Effects start on the causing frame, never a few frames later.

## 3. Choosing
| What changes between A and B | First choice | Alternatives |
|---|---|---|
| Only the state (same UI, new moment) | T1 + T2 | T18 |
| The ground (dark and light) | T3 | T15, T5 |
| The distance (same subject, different scale) | T14 | T12 |
| The subject (text to UI, UI to other UI) | T4 or T7 | T17 |
| One line of text to the next | T19 | T8 |
| Problem to product (the turn) | T21 or T11 | T3 |
| Product to brand (sign-off) | T21 into the logo, or T4 contraction | T16, T10 |
| Field or texture to logo or number | T10 | T9 |
| Montage | T20 | T1 on the beat |

## 4. Rules
- **No crossfades between scenes.** Fade only a single object (one line, the last phrase, a ghost behind a new hero).
- **Two or three transition types per film,** repeated. Shared-element morphs don't count against the budget. A new transition every seam reads as a template demo.
- **Plan both sides together** in the handoff table (`direction.md`) before animating either.
- **Build transitions from shapes already in the film:** the logo's shape, the brand colour, the carried dot or line, the product's own container.
- **One blur grammar:** crisp films use T1, T2, T4, T9, T10, T14, T19; smear films add T6 and blurred whips.
- **Cut cadence:** inside a beat cut every 0.3-2.3 s; let claims run 1.5-3 s with the proof the same length or longer; shorten scenes towards the end and let the last one linger.
- **Re-check a seam after any edit** to the first or last second of either scene, including re-timing to a new voiceover.
